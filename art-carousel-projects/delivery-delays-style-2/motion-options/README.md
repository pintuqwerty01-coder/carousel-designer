# Race to know — animated Style 2 preview options

These are two composition/motion treatments of the user's selected **B — Race to know** concept. A/B below label execution options, not a switch back to the earlier domino/blind-spot concepts.

| Preview | Direction |
|---|---|
| A — Reference composition | Narrow cover text column, tall edge-crossing 3D route, dashed swipe arrow, flares and bokeh. Aqua task with right-side text on a dark blob, ghost 2 to the left and a lower-edge route sculpture. |
| B — Wide editorial | Broad cover hook and large foreground route; aqua task mirrors the blob/text placement, with the oversized route crossing the right edge. |

Each option is an eight-second MP4: four-second cover, then four-second in-transit task. The individual slides are also preserved as `a-01.mp4`, `a-04.mp4`, `b-01.mp4`, `b-04.mp4`. Four-page `preview-options.pdf` and `compare.png` support still review.

Motion follows the supplied reference language: 7px object drift and ±0.6° rocking, an early-alert point travelling the aqua route, a small arrival ring, sequential vector check drawing, a blurred light sweep, breathing flare/bokeh, and arrow-box halo pulses. Text remains stationary. No mascot, product screen, unsupported metric or new marketing copy is introduced.

User selection is pending. These previews do not replace the current project proofs or authorise completion of the remaining seven. The copied real fonts and generated 3D assets are included. PNGs and MP4 frames are checked for copy, glyph bounds, image loading and stable text positions. Actual custom-font checks and MP4 technical metadata are recorded separately.
