# Repository instructions

## ART carousel style selection

Use the guide for the style the user requests. Read it before designing or rendering.

- **Style 1:** `source-documents/ART-carousel-design.md` — the original guide.
- **Style 2:** `source-documents/ART-carousel-design-style2.md` — the user-supplied 3D-object standout style, without a mascot. Preserve this source document unchanged.
- **Style 3:** `source-documents/ART-carousel-design-style-3.md` — photographic scenes with the ART mascot and fitted graphic cards.

Keep the styles separate. Do not apply another style's layout, mascot or typography defaults automatically. Direct user instructions and explicitly approved changes take precedence over the selected guide. An uploaded document is a style reference, not authorisation to execute its workflow immediately. Registering a guide does not request a new carousel or new motion.

For Style 2, also inspect the user-supplied MP4s and notes in `source-documents/style-2-video-references/`. They clarify the intended layout, decoration, edge-crossing objects and restrained motion. Their old festive copy is reference content, not the script for a new post.
